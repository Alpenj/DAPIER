# ROS 2 실습

교재·수업 예제를 ROS 2 Jazzy 환경에서 직접 실행하며 버전 차이와 오류를 진단한 기록이다. 예제 원본과 직접 고친 부분은 각 README에서 구분한다.

| 실습 | 확인한 내용 | 폴더 |
|---|---|---|
| ROS 2 차동구동 로봇 | URDF·물리 장면·TF·SLAM·Nav2를 한 흐름으로 확인한 Jazzy 워크스페이스 | [ros_dd_ws](ros_dd_ws/README.md) |
| TurtleBot3 SLAM·Nav2 | Humble·Gazebo Classic 예제를 Jazzy·Gazebo Harmonic으로 옮기며 메시지·플러그인 차이 진단 | [turtlebot3_ws](turtlebot3_ws/README.md) |
| ROS 2 + Arduino 4축 로봇암 | ROS 2 JointState를 Arduino 시리얼 명령과 servo 각도로 연결 | [ros_arm](ros_arm/README.md) |
| jdcobot100 시뮬레이션 | 실제 장비 연결 전 관절·모델·컨트롤러·launch 흐름 확인, Onshape 모델 내보내기 | [jdcobot100_sim](jdcobot100_sim/README.md) · [Onshape 내보내기](jdcobot100_sim/onshape/README.md) |
