# DAPIER 전력·계산 보드 예산

기준일: 2026-08-20

목표 구성은 TurtleBot3 Waffle Pi 위에 JDcobot200 두 팔과 RGB-D 카메라를 탑재하고,
이동 후 정지한 상태에서 신발을 집는 것이다. 아래 값은 **제조사 상한**, **이번 실측**, **설계
여유를 둔 권고**를 구분한다. 아직 측정하지 않은 실제 작업 평균 전류를 임의로 채우지 않는다.

## 현재 결론

- 기존 Raspberry Pi 4 한 대는 TurtleBot3의 OpenCR, 바퀴, LiDAR, ROS 2 bringup 전용으로 유지한다.
- 노트북을 로봇에 탑재하면 추가 계산 보드는 0대다. 양팔 USB와 RGB-D 카메라는 전원형 USB 3
  허브를 거쳐 노트북에 연결한다.
- 노트북을 로봇 밖에 두고 자유롭게 이동하려면 USB 장치의 종단이 될 탑재 계산 보드 한 대가
  추가로 필요하다. 이 경우 총 계산 보드는 기존 Pi 4 한 대와 추가 보드 한 대다.
- 외부 노트북에 양팔과 카메라를 USB로 직접 연결하는 구성은 정지 개발에는 쓸 수 있지만 이동
  로봇은 USB 케이블에 묶인다.
- 팔 전원을 Pi, USB 허브, OpenCR의 5V 출력에서 공급하지 않는다.
- 대용량 배터리는 필요할 가능성이 높지만, 작업 동작의 실제 평균/피크 전류를 측정하기 전에는
  용량을 확정하거나 구매하지 않는다.

## 근거가 있는 부하

| 부하 | 수량 | 전압 | 제조사 또는 관측 전류 | 계산 전력 | 상태 |
|---|---:|---:|---:|---:|---|
| STS3215 팔 서보 | 12 | 관측 12.1–12.3V, 정격 계산 12V | 무부하 0.18A/개, stall 2.7A/개 | 무부하 합계 25.92W, 동시 stall 이론값 388.8W | 모델·전압 실측, 전류 값은 제조사 |
| XM430-W210 바퀴 서보 | 2 | 권장 12V | 대기 0.04A/개, stall 2.3A/개 | 대기 0.96W, 동시 stall 이론값 55.2W | 모델은 Waffle Pi 사양, 전류는 제조사 |
| Raspberry Pi 4 | 1 | 5V | 권장 전원 용량 3A | 공급 설계 15W | 보드 모델 실측, 값은 제조사 권고 |
| RPLIDAR | 1 | 5V | A1이면 명목 0.1A | A1이면 0.5W | 런타임 계열만 확인, 정확한 라벨 미확인 |
| AADJA1300GX/Orbbec Astra 계열 | 1 | USB 5V | USB descriptor 최대 0.5A | 최대 선언값 2.5W | 이 PC에서 관측, 현재 분리됨 |
| 전원형 USB 허브·USB-서보 어댑터 | 1식 | 5V | 제품 선정 후 확인 | 미정 | 아직 제품 미선정 |
| 노트북 | 1 | 자체 배터리/정품 어댑터 | 실제 추론 부하 측정 필요 | 미정 | 기존 장비 사용 |

STS3215의 제조사 값은 [FEETECH STS3215 제품 사양](https://www.feetechrc.com/525603.html),
XM430 값은 [ROBOTIS XM430-W210 사양](https://emanual.robotis.com/docs/en/dxl/x/xm430-w210/),
Pi 전원은 [Raspberry Pi 4 데이터시트](https://datasheets.raspberrypi.com/rpi4/raspberry-pi-4-datasheet.pdf)를
근거로 한다. OpenCR은 5–24V 입력, 기본 11.1V 19.98Wh 배터리, 12V 4.5A SMPS,
5V 4A 출력을 제공하지만 12V와 5V 출력 합계가 55W를 넘지 않아야 한다
([OpenCR 1.0 사양](https://emanual.robotis.com/docs/en/parts/controller/opencr10/)).
RPLIDAR A1 명목값은 [SLAMTEC A1 사양](https://www.slamtec.com/en/Lidar/A1Spec)의 조건부 참고값이다.

stall은 모터가 멈춘 위험 상태의 순간 상한이며 정상 소비전력이 아니다. 반대로 무부하 값도 신발을
드는 실제 소비전력이 아니다. 두 값 사이의 작업 전류를 직접 측정해야 한다.

## 전원 계통 권고

벤치 개발 단계는 다음처럼 부하를 분리한다.

```text
AC 전원
├─ 비상정지 접점 ─ 12V 20A급 팔 A 전원 ─ 팔 A 서보 6개
├─ 비상정지 접점 ─ 12V 20A급 팔 B 전원 ─ 팔 B 서보 6개
├─ TurtleBot 기본 12V 4.5A SMPS 또는 기본 배터리 ─ OpenCR/바퀴/Pi/LiDAR
└─ 노트북 정품 전원 ─ 노트북 ─ 전원형 USB 허브 ─ 카메라/서보 어댑터
```

팔 하나의 제조사 동시 stall 계산은 `6 × 2.7A = 16.2A`다. 20A급 분기 권고는
`16.2A × 1.2 = 19.44A`의 설계 여유를 반올림한 것이다. 정격 20A를 계속 소비한다는 뜻은
아니다. 두 팔을 한 전원에 묶는다면 최소한 두 개의 개별 보호 분기와 충분한 순간 전류 능력이
필요하며, 초기 개발은 장애 격리가 쉬운 팔별 전원을 권장한다.

모바일 배터리 단계에서는 큰 팩을 부하에 직접 연결하지 않고 다음 분기로 나눈다.

```text
보호회로/BMS가 있는 주 배터리
├─ 고전류 DC/DC 12V ─ 보호 분기 ─ 팔 A
├─ 고전류 DC/DC 12V ─ 보호 분기 ─ 팔 B
├─ 안정화된 TurtleBot 전원 분기 ─ OpenCR/바퀴/Pi/LiDAR
└─ 필요 시 5V 분기 ─ 전원형 USB 허브/카메라
```

흔한 로봇청소기용 14.4V 배터리는 STS3215 관측 12V 계통에 그대로 연결하지 않는다. 배터리의
공칭전압뿐 아니라 완충전압, 연속/순간 방전전류, BMS 차단값, 셀 화학, 충전기 호환성, DC/DC
효율을 확인해야 한다. 퓨즈, 배선 굵기, 커넥터, 접촉기, 접지의 최종 선정은 실제 전류 측정 후
전기 안전 검토를 거친다.

## 배터리 용량 시나리오

사용 가능 용량을 명목 Wh의 80%로 제한하면 1시간 운용에 필요한 명목 용량은
`평균 소비전력 ÷ 0.8`이다.

| 실제 평균 부하 가정 | 30분 | 1시간 | 의미 |
|---:|---:|---:|---|
| 80W | 50Wh | 100Wh | 가벼운 동작 가정, 미검증 |
| 120W | 75Wh | 150Wh | 중간 설계 시나리오, 미검증 |
| 200W | 125Wh | 250Wh | 잦은 양팔 동작 가정, 미검증 |

이 표는 구매 사양이 아니다. 다음 네 상태에서 인라인 DC 전력계로 각 팔 분기와 베이스 분기를
따로 측정한 뒤 실제 평균값을 대입한다.

1. 토크 ON 정지 유지
2. 무부하 전체 관절 저속 이동
3. 실제 신발을 든 반복 동작
4. 안전하게 제한한 짧은 막힘/충돌 감지 상황

## 기구·운용 제한

TurtleBot3 Waffle Pi 제조사 표에는 최대 payload 30kg가 기재되어 있지만
([공식 하드웨어 사양](https://emanual.robotis.com/docs/en/platform/turtlebot3/features/)), 이는 두 팔을
앞으로 뻗었을 때의 전복 안정성이나 상판의 국부 굽힘, 동적 관성까지 보장하지 않는다. 양팔,
브래킷, 카메라, 배터리, 탑재 노트북의 실제 질량과 무게중심을 재고 다음을 확인해야 한다.

- 팔을 최대로 뻗은 최악 자세에서도 투영 무게중심이 바퀴 지지 다각형 안에 남는지
- 정지 브레이크 없이 팔 반력으로 베이스가 밀리지 않는지
- 이동 중에는 팔을 접은 수납 자세로 고정하고, 베이스가 정지 허용치 안에 든 뒤에만 집기를 허용하는지
- 비상정지가 팔의 12V 동력은 차단하되 Pi/노트북 로그는 유지하는지

## 아직 확정할 수 없는 값

- 양팔의 실제 작업 평균·순간 피크 전류와 열 상승
- 정확한 LiDAR 모델 라벨과 시작 전류
- 탑재 노트북의 AI 추론 중 소비전력 또는 추가 계산 보드의 전력
- 프레임·팔·배터리·노트북의 질량 및 전체 무게중심
- 요구 운용시간

이 값들을 얻기 전에는 배터리 Wh, BMS 전류, DC/DC 모델, 퓨즈와 배선을 구매 사양으로 확정하지 않는다.
