# 이동형 양팔 로봇 신발 정리 프로젝트 요구사항 원장

- 최초 기록일: 2026-08-19
- 현행 하드웨어 반영일: 2026-09-03
- Ouroboros 인터뷰 세션: `interview_20260819_070643`

## 1. 프로젝트 목표

이동형 양팔 로봇이 시작 위치에서 박스 위치 B까지 이동하고, 오른팔로 박스 앞 날개를 들어
몸에서 멀어지는 방향으로 뚜껑을 연다. 왼팔은 박스 안 신발을 꺼내고, 로봇은 신발을 든 채
시작 위치로 복귀해 내려놓는다. 초기 MuJoCo 신발은 직육면체 proxy를 사용한다.

30켤레 인식·짝추론·신발장 정리는 위 단일 박스 sequence가 실물에서 반복 성공한 뒤의 확장
목표이며 현재 MVP 완료 조건으로 사용하지 않는다.

취업 포트폴리오의 주력 포지션은 **Robotics AI / VLA·이미테이션 러닝 엔지니어**로 설정한다.

## 2. 확정된 하드웨어

- 양팔 로봇: 동일한 SO-101 두 대, 팔당 STS3215 6개(5관절+그리퍼)
- 모바일 베이스: TurtleBot3 Waffle Pi
- 바퀴 모터: XM430-W210-T
- 작업공간 RGB-D: HP-ASC-H201 (`3438:0173`), 기둥 상단 top-view
- 전면 SLAM RGB-D: Orbbec Astra S (`2bc5:0402`), TurtleBot3 전면 카메라 bracket
- 손목 카메라: 좌·우 SO-101에 USB UVC RGB 한 대씩
- edge 연산 장치: Raspberry Pi 4, base·경량 I/O·health/watchdog 담당
- 로컬 연산 장치: ASUS TUF Gaming A16 / RTX 5050, perception·IL·LLM 담당
- Visual SLAM 실행 위치: Pi 4와 노트북 실측 부하·지연 비교 후 확정
- 텔레오퍼레이션 장치: 미정
- 현재 조립 상태: 양팔·좌우 wrist RGB·H201·Astra USB 연결 이력 있음; 최종 탑재 실측 필요
- 추가 장비·재료 예산: 0원

장치 역할·stable alias의 기계 판독 정본은 `2ARM_ROBOT/config/hardware_roles.json`이다.
controller serial, 비밀번호와 calibration 원본은 저장소에 넣지 않는다.

## 3. 시스템 구조

### 이동·인지

- 전면 Astra S RGB-D와 휠 오도메트리로 visual SLAM 및 위치 추정
- H201 top-view RGB-D로 박스·신발 위치를 인식하고 docking 후 다시 관측
- 좌·우 wrist RGB로 그리퍼 근접 접근과 접촉 전후 상태를 관측
- LiDAR는 현재 MuJoCo·Visual-SLAM active sensor path에서 제외하며 실제 장착 여부를 추정하지 않음

### 학습·정책

- 기준선: 이동 IL + 근접 조작 IK의 hybrid, 필요 구간에서 ACT 양팔 정책 비교
- 상위 계층: 신발 인식, 짝 추론, 스킬 선택, 실패 복구
- 확장선: VLA 정책을 추가하여 ACT 기준선과 비교
- 비교 지표: 성공률, 미학습 신발 일반화, 데이터 효율, 추론 지연시간

### 학습 신발과 신규 신발 처리

- 학습에 사용한 신발 30켤레는 전부 end-to-end 정리 대상으로 삼는다.
- 신규 신발은 별도의 재학습 없이 VLM API 또는 시각 임베딩으로 같은 신발의 좌우 짝을 추론한다.
- LLM은 짝 후보 검증, 빈 배치 위치 선택, 작업 순서와 실패 복구를 담당한다.
- 실제 관절 행동은 LLM이 직접 생성하지 않고 검증된 이동 IL·IK/ACT 조작 스킬만 제안한다.
- 바닥 격자 단계에서는 같은 신발끼리 짝지어 나란히 정렬한다.
- 신발장 단계에서는 같은 신발의 좌우를 한 슬롯에 나란히 수납한다.
- 짝 판정 신뢰도가 기준보다 낮거나 API 호출에 실패하면 미분류 보관 위치에 두고 사용자 확인 대상으로 표시한다.

## 4. 정리 난이도 단계

1. 바닥의 지정 격자에 신발 짝을 맞춰 정렬
2. 한 켤레씩 개방형 칸에 배치
3. 신발장 슬롯에 좌우와 방향을 맞춰 최종 수납

최종 평가에는 학습 데이터에 없던 디자인·색상·크기의 신발을 포함한다.
