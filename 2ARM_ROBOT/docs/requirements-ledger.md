# 이동형 양팔 로봇 신발 정리 프로젝트 요구사항 원장

- 기록일: 2026-08-19
- Ouroboros 인터뷰 세션: `interview_20260819_070643`

## 1. 프로젝트 목표

이동형 양팔 로봇이 실내에 무작위로 놓인 신발 30켤레(총 60개)를 인식하고, 학습에 없던 신발의 짝도 추론하여 단계적으로 정리한다.

취업 포트폴리오의 주력 포지션은 **Robotics AI / VLA·이미테이션 러닝 엔지니어**로 설정한다.

## 2. 확정된 하드웨어

- 양팔 로봇: JDcobot300
- 모바일 베이스: TurtleBot3 Waffle Pi
- 구동 모터: XM430-W210-T
- 모터 변경 조건: 양팔·프레임·배터리 탑재 후 토크가 부족하면 변경 검토
- Depth camera: Orbbec Astra Pro
- 연산 장치: ASUS TUF Gaming A16, RTX 5050
- 텔레오퍼레이션 장치: 미정
- 현재 조립 상태: 부분 조립
- 추가 장비·재료 예산: 0원

## 3. 시스템 구조

### 이동·인지

- Astra Pro RGB-D와 휠 오도메트리로 visual SLAM 및 위치 추정
- TurtleBot3 LDS-02는 Nav2 장애물 회피와 안전 costmap에 사용
- Astra Pro는 신발 인식과 3D 위치 추정에도 사용

### 학습·정책

- 기준선: ACT 기반 양팔 조작 정책
- 상위 계층: 신발 인식, 짝 추론, 스킬 선택, 실패 복구
- 확장선: VLA 정책을 추가하여 ACT 기준선과 비교
- 비교 지표: 성공률, 미학습 신발 일반화, 데이터 효율, 추론 지연시간

### 학습 신발과 신규 신발 처리

- 학습에 사용한 신발 30켤레는 전부 end-to-end 정리 대상으로 삼는다.
- 신규 신발은 별도의 재학습 없이 VLM API 또는 시각 임베딩으로 같은 신발의 좌우 짝을 추론한다.
- LLM은 짝 후보 검증, 빈 배치 위치 선택, 작업 순서와 실패 복구를 담당한다.
- 실제 관절 행동은 LLM이 직접 생성하지 않고 학습된 ACT 집기·운반·배치 스킬을 호출한다.
- 바닥 격자 단계에서는 같은 신발끼리 짝지어 나란히 정렬한다.
- 신발장 단계에서는 같은 신발의 좌우를 한 슬롯에 나란히 수납한다.
- 짝 판정 신뢰도가 기준보다 낮거나 API 호출에 실패하면 미분류 보관 위치에 두고 사용자 확인 대상으로 표시한다.

## 4. 정리 난이도 단계

1. 바닥의 지정 격자에 신발 짝을 맞춰 정렬
2. 한 켤레씩 개방형 칸에 배치
3. 신발장 슬롯에 좌우와 방향을 맞춰 최종 수납

최종 평가에는 학습 데이터에 없던 디자인·색상·크기의 신발을 포함한다.
