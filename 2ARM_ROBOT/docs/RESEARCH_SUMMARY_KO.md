# 양팔 조작 연구 기록 | 전형주

파지가 풀리거나 손끝이 목표에서 벗어났을 때, 모델 전체를 바꾸기보다 어느 조건이 결과를 바꾸는지 확인했다. 아래는 공개 코드와 실험 기록을 연결한 요약이다. 수치는 각 실험 당시의 조건에 한정하며, 원시 로그·장치 보정과 학습 데이터의 비공개 자료는 포함하지 않는다.

[프로젝트 소개](../README.md) · [전체 포트폴리오](../../README.md)

## 1. 접촉은 생겼는데 블록을 들지 못했다

팔에 장착한 그리퍼는 파지 확인 단계를 통과했지만 들기 단계에서 접촉을 잃었다. 손가락이 닿았는지만으로는 블록의 무게와 회전 모멘트를 지탱할 수 있는지 알 수 없었다. 접촉 위치, 법선 방향과 힘의 상한을 같은 상태에서 비교했다.

공개된 중력 wrench 분석에서는 20 g 블록에 대해, 관찰된 접촉과 법선력 상한 아래에서 지지 가능한 질량의 독립 상계가 파지 확인 상태에서 7.864 g, 추가 닫기 상태에서 12.368 g으로 계산됐다. 이는 그 접촉 조건으로 하중을 지지하기 어렵다는 진단이었다. 실물 그리퍼의 최대 파지 능력을 측정한 값은 아니다.

이후 그리퍼 단독 A0와 팔 장착 A2의 추가 닫기를 비교했다. 양쪽 접촉 이후 집게 간격 감소는 A0에서 31.357 µm, A2에서 2.100 µm였다. 동일한 A2 전체 상태에서 닫기 조건을 맞추자 양쪽 법선력이 0.102/0.117 N에서 0.445/0.460 N으로 증가했다. 후속 들기에서는 테이블에서 떨어진 상태와 양측 접촉을 유지했지만, 다음 끝점 검사에서 멈췄다.

접촉 여부, 접촉 후 압축, 하중 지지와 작업 전체의 성공을 각각 기록해야 했다. 추가 닫기가 유효했던 비교를 모든 물체에 적용되는 일반적인 해결책으로 보지는 않았다.

근거: [접촉·wrench 분석, PR #64](https://github.com/Alpenj/DAPIER/pull/64), [후속 동일 상태 비교, PR #67](https://github.com/Alpenj/DAPIER/pull/67). #64는 병합된 진단 코드이며 #67은 닫힌 미병합 연구 이력이다.

## 2. 끝점 오차를 계획 잔차와 실행 추종으로 나눴다

파지를 유지한 뒤 LIFT15 끝점에서 TCP 오차가 0.611845 mm로 나타났다. 기존 기준은 0.5 mm였다. 기준을 완화하지 않고 목표에서 계획된 FK 위치까지의 잔차와, 계획된 위치에서 시뮬레이션의 실제 위치까지의 차이를 분리했다. 두 벡터의 크기를 단순히 더해 전체 오차로 해석하지 않았다.

같은 상태에서 기존 DLS 계산을 한 번 더 적용하자 계획 FK 잔차는 0.407734 mm에서 0.157147 mm로 줄었다. 실행 후 TCP 오차도 0.611845 mm에서 0.358577 mm로 줄어 기준을 충족했다. 이후 LIFT30 오차는 0.335685 mm였다.

계획 단계에서 기준을 간신히 만족한 해는 실행 추종 오차를 더한 최종 결과에서 실패할 수 있었다. 이 조건에서는 계획 잔차를 더 줄이는 수정이 유효했다. 이 실험은 복사한 동일 상태에서의 비교이며, 기본 시작 자세부터의 전체 작업이나 실물 끝점 정확도를 검증한 것은 아니다.

근거: [고정 커밋 65b0231](https://github.com/Alpenj/DAPIER/commit/65b023176f741024b1290480f99d2c88fbfc822b), [PR #67의 LIFT15 비교](https://github.com/Alpenj/DAPIER/pull/67).

## 3. 공중 유지 중 미끄러짐은 별도로 확인했다

블록을 들어 올린 뒤에도 양측 접촉은 유지됐지만 높이가 서서히 낮아졌다. 동일한 공중 유지 상태에서 시작해 진단용 NoSlip 설정만 바꿨다.

| 3초 관찰 | NoSlip=0 | 진단용 NoSlip=5 |
|---|---:|---:|
| 블록 높이 변화 | −3.054448 mm | −0.002985 mm |
| 종료 시 수직 속도 | −0.984277 mm/s | −0.001187040 mm/s |

이 비교는 해당 상태의 미끄러짐이 접촉 솔버 설정에 민감함을 보여줬다. 실물 마찰을 개선한 결과는 아니며, 잔류 속도가 작은 것을 무한 시간의 평형으로 해석하지 않았다.

진단 뒤에는 단계별 솔버 전환을 피하고 NoSlip=0 / impratio=100을 전 구간에 적용하는 후보를 검토했다. 복사한 상태에서 이어 실행한 후보는 추가 3초 HOLD를 통과했으며, 그동안 블록 하단 높이는 약 0.0423 mm 낮아졌다. 이 결과와 기본 시작 자세부터의 실행은 따로 평가했다.

근거: [동일 상태 NoSlip 비교 커밋 f38900d](https://github.com/Alpenj/DAPIER/commit/f38900db5e5f5f5f0de8d72ff6276cb5b95f9a93), [전 구간 후보 커밋 8270d91](https://github.com/Alpenj/DAPIER/commit/8270d9142e890313b8c4bcc1f241ed818674b2e7), [PR #67](https://github.com/Alpenj/DAPIER/pull/67).

## 4. 기본 시작 자세에서 3초 HOLD까지 연결했다

일부 상태에서 성공한 동작이 시작 자세부터도 이어지는지 확인했다. 접근 경로의 copied/live 실행을 같은 구간과 시간으로 비교하고, 불일치가 있으면 최종 성공 판정이 나오지 않도록 검증 경로를 연결했다.

2026-09-21의 후보 커밋 `f6b61dbc81273f6d775d96f7950461fac9113cbb`에서 normal HOME, 접근, CLOSE, LIFT와 HOLD를 하나의 연속 SIM으로 실행한 기록은 다음과 같다.

| 항목 | 기록된 결과 |
|---|---:|
| 전체 물리 계산 | 18,203 step / 36.406 s |
| HOLD 구간 | 1,500개 표본 / 3.000 s |
| 접근 copied/live 비교 | 5,582개 표본 일치, 마지막 적분 상태 별도 일치 |
| HOLD 중 테이블 접촉 | 0 |
| HOLD 중 최저 블록 하단 높이 | 33.864400 mm |
| 일반 clearance 전 구간 최소 | 30.769597 mm |
| 경고·액추에이터 포화 | 없음 |

고정 장면의 단일 후보 실행 결과다. 여러 초기조건의 신뢰도, 학습한 ACT 정책의 성공률이나 실물 집기 성공을 뜻하지 않는다. 결과를 재현하려면 같은 후보 소스와 입력·환경이 필요하다. 기록된 검사를 이번 문서 갱신에서 다시 수행하지는 않았다.

근거: [후보 커밋 f6b61db](https://github.com/Alpenj/DAPIER/commit/f6b61dbc81273f6d775d96f7950461fac9113cbb), [PR #68의 실행·검증 기록](https://github.com/Alpenj/DAPIER/pull/68). 2026-10-08 확인 기준 PR은 닫혔으며 미병합이다. 이 결과를 현재 `main`의 기본 실행 결과로 표시하지 않는다.

## 5. 계산이 맞는 것과 실물 영점이 맞는 것을 구분했다

2026-09-30에는 같은 저장 관절값이 두 변환 경로에서 다른 팔꿈치 각도로 나타나는 문제를 조사했다. 오프셋 차이에 따른 계산 결과와, 어느 후보가 실제 기구의 영점에 부합하는지는 다른 질문이었다.

먼저 완료한 파일 계산을 보존하고, CAD의 기준 모서리와 같은 자세의 관절 읽기를 비교할 측정 절차를 준비했다. 사진의 정성적인 평행 관찰만으로 정밀한 영점을 채택하지 않았다. 카메라의 재투영 오차가 작다는 것 역시 실제 거리·좌표 변환의 정확도를 독립적으로 보장하지 않았다.

공개한 것은 소스 일부와 측정 안내, 구간 판정 helper다. 비공개 입력과 로컬 의존성이 제외되어 완전한 독립 실행 묶음은 아니다. 실제 관절 영점의 채택과 제한 모션은 해당 기록에서 미완료로 남겼다.

근거: [후보 커밋 3720da1](https://github.com/Alpenj/DAPIER/commit/3720da1ee678793480035cbfa3db96a546c73671), [PR #70](https://github.com/Alpenj/DAPIER/pull/70). 2026-10-08 확인 기준 닫힘·미병합이다.

## 코드와 연구 기록을 읽는 기준

내 주 담당은 모방학습·시뮬레이션·Sim-to-Real이다. Visual SLAM은 팀원 주 담당 모듈에 설계·구현 협업으로 참여했다. 외부 코드·자산의 출처와 팀 기여는 각 저장소에서 구분한다.

위 기록은 공개 PR과 고정 소스를 연결한 연구 요약이다. 계획, 코드 구현, 모의 검사, 물리 시뮬레이션과 실물 시험을 같은 완료 상태로 세지 않는다. 닫힌 후보 PR을 이번 문서 작업으로 병합하거나 런타임에 채택하지 않았다. 원시 데이터·보정값·실행 승인도 변경하지 않았다.

문서 갱신: 2026-10-08. 현재 장비·코드의 전체 검증 보고서가 아니라, 기록된 비교 실험을 읽기 위한 문서다.
