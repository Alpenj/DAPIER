비활성 대안: upper holder 제거 실험

기본 MuJoCo 모델과 제작 기준이 아닙니다. 비교·회귀 조사용으로만 보존합니다.

이 폴더의 STEP/STL은 원본 assem_base.step 상부에서 좌우 holder envelope를 BRep boolean으로 제거한 이전 대안입니다. 현재 활성 설계는 원본 upper socket을 유지하고, stock SO-101의 base_so101_v2만 대신합니다. base motor holder, Waveshare mounting plate, base servo와 shoulder 이후 관절 체인은 유지한 채 socket에 끼우는 구조입니다.

  • 활성 upper: ../../assem_base_upper.stl
  • 활성 조립 기준: 프로젝트 README.md와 TOWER_FABRICATION.md
  • 재생성기: ../../../prepare_upper_holder_removed.py

이 대안 파일을 slicing하거나 실물 제작에 사용하려면 별도 설계 승인과 체결 검증이 필요합니다.
