1. 공통 플랫폼 목표

회의의 중심 질문은 하나의 물체가 아니라 이동·인지·양팔 조작·학습 자산의 재사용성이다.

RGB-D로 주변 대상을 이해하고, TurtleBot3로 접근하며, SO-101 양팔로 안전하게 조작한 뒤 결과를 재관측하고 실패를 복구하는 플랫폼을 어떤 과제로 검증할 것인가?

2. 회의용 프로젝트 후보 A·B·C

세 후보는 같은 하드웨어·ROS·MuJoCo·ACT·안전 기반을 공유하지만, 인지와 양팔 조작의 성격이 다르다. 회의에서는 주력 하나와 축소형 예비안 하나를 정한다.

PLAN A · 현재 주력

신발 한 켤레 탐색·정리

pair matching + mobile manipulation
  • 현관·정리 공간을 탐색해 신발 탐지
  • 특징을 비교해 동일한 신발의 짝 판단
  • 짝이 있는 위치로 이동 후 base 고정
  • 양팔로 좌우 신발 파지·자세 정렬
  • 신발장 또는 지정 영역에 한 쌍 배치
  • 재관측 후 retry·regrasp·safe stop
장점 현재 Waffle·중앙 지지대·shoe task·pairing 구상과 가장 잘 연결된다.
핵심 위험 신발의 변형, 다양한 재질·바닥 마찰과 grasp 불확실성.
PLAN B · 양팔성 강조

수건·의류 펼치기/접기

deformable object bimanual manipulation
  • 바구니 또는 작업대에서 수건 한 장 선택
  • 모서리·주름·겹침 상태를 RGB-D로 추정
  • 양팔로 두 점을 잡아 펼치고 장력 유지
  • 정해진 순서로 반 접기·재파지
  • 크기/종류별 바구니에 분류
  • 초기 MVP는 base 고정·수건 한 종류
장점 양팔이 필요한 이유와 ACT imitation learning 가치가 가장 명확하다.
핵심 위험 deformable perception·접촉 모델·데이터 수집 난도가 가장 높다.
PLAN C · 이동성 강조

생활물품 테이블 세팅·회수

navigation + rigid-object arrangement
  • 가벼운 플라스틱 컵·접시·수저 탐지
  • 보관 위치와 테이블 사이를 이동
  • 한 팔 pick, 양팔 tray/긴 물체 협업
  • 좌표 template에 맞춰 정해진 순서로 배치
  • 사용 후 물품 회수·분류·누락 확인
  • 뜨거운 음식·액체·유리·칼은 범위 제외
장점 TurtleBot 이동과 배치 정확도를 관객이 쉽게 이해한다.
핵심 위험 지지대 안정성, payload, 이동 후 localization·camera 정합.
비교 기준Plan A 신발Plan B 수건·의류Plan C 테이블 세팅

이동 플랫폼 활용높음낮음→바구니 운반 시 중간매우 높음

추천 위치주력안양팔 연구 대안통합 데모 대안

3. Plan A 개발 Phase 1→2→3

아래는 프로젝트 후보 A/B/C가 아니라, 신발 정리 주력안을 선택한 뒤의 개발 진행 단계다. 각 Phase에서 기획부터 demo와 회고까지 한 바퀴를 완주한다.

PHASE 1 · THIN SLICE

신발 한 짝 end-to-end

알려진 위치 → 가까운 목표 zone
  • 공식 좌표 transform과 MuJoCo free shoe
  • MOCK/기본 pose perception contract
  • 한 팔 DLS IK + 7차 trajectory
  • JD-edu ACT 첫 학습과 offline replay
  • simulation-only 20-trial 평가
완료 gate
20회 중 16회 성공 또는 모든 실패 원인 분류, ACT checkpoint 재현, fit coupon 검증.
PHASE 2 · PAIR MVP

양팔 한 켤레 정리

RGB-D 인식 → 좌우 slot 정렬
  • pair matching·좌우/자세 추정
  • 양팔 reachability·handoff·regrasp
  • ACT Receding Horizon 비교
  • ACT Temporal Ensembling 비교
  • jitter·latency·복구 scenario 평가
완료 gate
한 켤레 성공률, 정렬 오차, cycle time, action age, actual jerk와 intervention 결과 고정.
PHASE 3 · MOBILE

이동·다품종·실패복구

여러 켤레·가림·장소 확장
  • 탐색·matching·목표 위치 navigation
  • tracking·occlusion·scene memory
  • long-horizon recovery policy
  • active data와 unseen shoe 평가
  • SmolVLA는 gate 후 선택 비교
완료 gate
scenario matrix에서 success, recovery, intervention과 safety가 반복 가능하게 남아야 한다.

5. LLM 기반 전체 작업 감독기

LLM은 모터를 직접 제어하지 않는다. 자연어 목표와 관측 결과를 해석해 허용된 고수준 skill을 선택하고, 결정론적 state machine·navigation·ACT/IK 실행기와 독립 safety supervisor를 조율한다.

사용자 목표
RGB-D·로봇 상태
LLM 계획·skill 선택
schema·precondition 검사
Navigation / ACT / IK
Safety gate
재관측·재계획

LLM이 할 수 있는 것

  • 탐색, 접근, 집기, 전달, 정렬, 놓기, 복구, 중단 skill 선택
  • 신발·수건·생활물품 task 순서와 좌우 팔 역할 계획
  • 실패 원인을 관측과 execution trace로 분류하고 제한 횟수 재계획
  • 사람에게 선택·승인·추가 관측이 필요한 시점 설명

LLM이 절대 할 수 없는 것

  • joint target, torque, velocity 또는 raw ROS actuator command 생성
  • 충돌·jerk·watchdog·base-arm interlock 우회
  • 실물 승인 문자열 생성·대리 승인 또는 자동 hardware enable
  • schema 밖 명령 실행, 무한 retry, 관측이 오래된 상태에서 진행
계층입력/출력실패 시 동작
LLM supervisorgoal + typed world state → skill proposal JSONparse/schema 실패 즉시 정지·재질문
Task executor허용 skill → 결정론적 precondition/state transition실패 코드와 새 관측을 반환
Motion policyACT/IK/navigation의 bounded targettimeout·tracking·jitter gate에서 중단
Safety supervisorcollision, freshness, limits, E-stop, HW 승인항상 최종 거부권, LLM 우회 불가

LLM 진입 gate: 먼저 Phase 1의 deterministic state machine과 ACT/IK skill이 같은 입력·출력 schema로 통과해야 한다. 이후 replay 가능한 simulation에서만 LLM을 붙여 skill 성공률, 계획 latency, invalid proposal, recovery 횟수와 사람 개입을 기록한다.

7. 기구·3D 출력 전략

K1 Max에서 바로 출력할 수 있는 최종 파일은 실측과 slicer 조건이 닫힌 revision에만 제공한다.

확인됨

  • Creality K1 Max
  • build volume 300×300×300 mm
  • Hyper PLA Black
  • filament 1.75 mm · 1 kg
  • 하부 STL 160×180×170 mm
  • 원본 상부 STL 110.963×254×156 mm
  • upper socket 원본 STL 110.963×254×156 mm
  • Z=160~170 mm, 10 mm 조립 중첩

아직 필요

  • 현재 장착 nozzle 지름
  • slicer와 정확한 version
  • SO-101 나머지 hole pattern·두께
  • camera 실제 모델·직접 고정면
  • 팔·중앙 지지대·camera 질량/COM

최종 산출물

  • 파라메트릭 CAD source
  • STEP · STL · 3MF
  • fit coupon
  • BOM·볼트·insert 규격
  • K1 Max 전용 revision G-code

지지대 본체를 바로 장시간 출력하지 않는다. Waffle adapter coupon → 큰 shoulder hole coupon → camera cradle coupon → dummy-load support → 최종 분할 지지대 순서로 진행한다. assembly 높이 316 mm는 K1 Max Z=300 mm를 넘지만 하부 170 mm와 상부 156 mm로 분할되어 각각 출력 범위 안에 들어간다.

8. 전체 팀 회의에서 결정할 것

제품·평가

  1. 주력 프로젝트 A/B/C 선택과 축소형 예비안 결정
  2. 신발안 선택 시 신발 종류, 시작 자세, 목표 zone과 20회 조건
  3. B의 최종 한 켤레 형상과 양팔이 필요한 이유
  4. 성공률, 정렬 오차, cycle time, 개입·복구 지표
  5. C에 이동과 여러 켤레를 넣는 진입 gate

학습·데이터

  1. JD-edu ACT 재현 dataset와 checkpoint 기준
  2. Receding Horizon·Temporal Ensembling 통제 변수
  3. 카메라·annotation·train/validation/test split
  4. SmolVLA 최대 GPU 시간·기간·중단 조건

기구·안전·일정

  1. camera와 SO-101 실측 담당·기한
  2. upper socket Z=394.051 mm·간격 254 mm와 camera mast 허용 범위
  3. PLA prototype 보강 시점과 proof load
  4. 각 단계 HW 승인자·E-stop·중단 기준
  5. 산출물 owner, reviewer, demo 날짜
회의 종료 조건
“좋아 보인다”가 아니라 담당자, 입력값, 측정법, 완료 gate와 다음 review 날짜가 각 항목에 배정되어야 한다.
