## 2. 주요 변경 (native/revision)
- **IK 시작값:** IK를 가르친 pregrasp 관절값에서 시작한다(home 시작은 팔 모양이 달라 손목 화면·모델 오차가 바뀜).
- **블록 방향:** 첫 계획의 블록 yaw = 가르친 잡기 방향(90° 대칭). 헤드 depth 윗면 최소사각형 각도가 그보다 12° 넘게 다르면 그 각도를 쓴다.
- **잡기 높이:** 가르친 잡기 높이 + 4 mm보다 낮게 가지 않는다. 블록 바로 위 정지점은 가르친 높이 + 그 단계에서 올린 양만 쓴다.
- **이미지 자코비안 정렬 루프**
  - 통과 기준은 가르친 화면이다: pregrasp 5 mm, 블록 위는 패드 여유 −0.3 mm, 앞뒤 5 mm, 각도 3°.
  - 옆 gain은 매 화면 블록 크기(px/mm)로 계산하고 학습하지 않는다.
  - yaw 부호는 팔별 실측값(우 +1.05, 좌 +1)이다.
  - Broyden 학습은 4 mm/3° 이상 움직였을 때만, 물리 부호는 고정한다.
  - 옆 이동이 8 mm를 넘으면 먼저 20 mm 올라간 뒤 옆으로 간다.
  - 오차 증가 판정은 공통 특징(옆·각도)만 비교한다.
  - 윤곽이 온전하면 손목 yaw를 한 번에 30°까지 돌린다.
- **집기 직전 판정**
  - 관절이 잡기 목표에 도착했으면(20 tick 이내) 내려간 것으로 본다.
  - 패드가 블록 윗면 아래에 있고 관절이 목표에 있으면, 모델의 패드 간격 값은 진단용으로만 쓴다.
  - 가운데 허용치는 패드 여유 + 2 mm, 각도 기준은 가르친 화면이다. 패드가 내려간 뒤에는 15°까지 허용한다(아래 §4에서 재검토 대상).
- **운반:** carry / carry_back 단계와 5 s 집게 감시를 추가했다. 운반 목표는 모델 범위 안으로 조정하고, 거부되면 공중에서 멈추지 않고 내려놓는다.
- **실행기(move_a)**
  - 이동 중 읽기는 0.05/0.2/0.5 s 간격으로 재시도하고, 마지막 시도 전에 포트를 다시 연다. 쓰기는 반복하지 않는다.
  - 정지 확인 읽기는 8회로 줄였다.
- **진행 감시:** following lead 50 → 60 tick(우 어깨 실측 53, `sweepick_progress_profile.json`에 근거 기록).
- **경로 판정(trajectory):** 모델 관절 범위 밖에서 출발해 안으로만 들어가는 경로는 진단으로 처리한다(나가는 경로는 그대로 거부).
- **prepare:** 측정된 접힌 시작자세가 모델에서 자기 겹침일 때, 경로 앞부분에서만 겹치고 그 뒤로 깨끗하면 허용한다(진입 구간 확인 표시 포함).
- **카메라 판독기(local_loop):** 손목 카메라가 끊기면 같은 확인된 포트로 10 s 동안 다시 연결한다.
- **녹화(episode):** 헤드 RGB는 3 FrameSet마다, 가로 640 px로 저장한다(3.6 GB → ~1 GB). depth는 6 FrameSet마다 저장한다.
- **속도**
  - 정렬 중 화면 확인은 헤드 블록 탐색을 생략한다(lite).
  - 빈손 정렬·블록 위 하강은 0.3 rad/s, 운반은 0.6 rad/s다. 하강·집기·들기·내려놓기는 0.15 rad/s를 유지한다.
  - 먼 팔 계획을 생략하고, 가장 작은 기울기가 되면 더 큰 기울기는 계획하지 않는다.
- **비상 복귀:** abort_home은 소스 변경 감시에서 예외로 둔다.

## 4. 심화 탐구 3종과 현재 방식 비교 (2026-10-18 밤)
하루 동안의 실패를 정리한 뒤 직접 세 갈래로 탐구했다: ① 집게·블록 기하와 시간 구성 계산, ② 연속 시각 서보로 가는 교사 V2 설계, ③ 연속 visual servo·squeeze·ACT 데이터 문헌 조사. 오늘 성공한 교사를 깨지 않기 위해 **이번 브랜치에는 코드 반영을 하지 않았다.** 다음 단계 계획으로만 기록한다.

|---|---|---|
| ρ4(4θ 일관성)는 직선 하나여도 1 → '사각형 전체 관측' 근거 아님 | 잘린 윤곽 각도 사용 조건 ≥0.45 | 맞다. 단, 경계 선분을 제외한 블록 모서리 하나의 방향은 블록 각도로 유효(대칭 mod 90). '사각형 관측' 근거로 쓰지 않도록 의미를 명시. 반례 테스트 추가 예정 |
