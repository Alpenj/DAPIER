# Dependencies and source attribution

This folder contains project source and selected project support modules. Existing copyright, license and provenance comments in copied source remain applicable. No new license is granted to third-party assets by this review snapshot.

The following dependencies are imported, not vendored: LeRobot and its Feetech motor integration, scservo_sdk, MuJoCo, NumPy, SciPy, PyTorch, OpenCV, FastAPI, Starlette, Uvicorn, AnyIO and Pillow. Their upstream distributions retain their respective licenses. The proprietary camera SDK/helper and robot/model assets are not redistributed here; their installation and redistribution terms must be checked separately.

Existing repository attribution continues to apply. This folder does not claim upstream libraries, external models, or team contributions as original project work.
